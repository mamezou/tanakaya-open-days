# プロダクト概要

## プロダクト名

田中屋 営業日カレンダー（`tanakaya-open-days`）

## 概要

ヴィーガンラーメン店「田中屋」の営業日を1つの設定ファイルで管理し、公開ページとLINEの前日配信に自動で反映する。Kiro University Challenge の最終課題として作る。計画の正本は `docs/plan.md`。

## 利用者

- お客様：公開ページを見る人と、LINE公式アカウントの友だち
- 運用者：開発者1名。設定ファイルを書き換えてデプロイする

## 営業ルール

- 既定の営業日は、設定ファイルの営業曜日（`openWeekdays`）に当たる日。田中屋は日曜だけ。営業曜日はコードに固定しない
- 祝日の扱いは範囲外。祝日に営業や休業をするときは、例外として登録する
- 例外は「休業日」と「臨時営業日」の2種類で、日付単位で登録する。持つのは日付と種別だけ
- 休業日は既定の営業日を休みにする。臨時営業日は既定外の日を営業にする
- 営業時間は設定ファイルの値で、コードに固定しない
- 日付と時刻の判定は、すべて日本時間（Asia/Tokyo）で行う

## 用語

| 用語 | 意味 |
|---|---|
| 営業曜日 | 設定ファイルで指定する、既定で営業する曜日。田中屋は日曜だけ |
| 既定の営業日 | 曜日が営業曜日に含まれる日 |
| 例外 | 休業日または臨時営業日として登録した日 |
| 対象日 | 前日配信で案内する日。実行日の翌日（日本時間） |
| 前日配信 | 対象日の前日の設定時刻に、LINEの友だち全員へ送る案内 |
| 設定ファイル | `data/settings.json`。git では管理しない。見本は `data/settings.example.json` |
| お知らせ | 設定ファイルに日付ごとに書く1行の文と任意のリンク。前日配信と公開ページに出す。例外とは別の項目で、営業可否を変えない |

## お客様向けに出す情報と出さない情報

- 出す：今日の営業可否、営業時間、今月と来月の営業カレンダー、LINEの友だち追加リンク、Instagramへのリンク、お知らせ（日付、文、リンク）
- 出さない：配信記録、AWSのリソース名（公開ページのURLを除く）、トークン、運用者の個人情報
- 公開用データには、表示に使う項目だけを入れる
